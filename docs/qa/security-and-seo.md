## Webhook signature rejection

POST `/api/webhooks/shopify` with a deliberately invalid `X-Shopify-Hmac-Sha256`:

- Response: **401 Unauthorized** — `{"ok":false,"error":"invalid signature"}`
- Verdict: PASS — not accepted.

`docs/webhooks.md`: the receiver answers **500** when `SHOPIFY_WEBHOOK_SECRET` is unset (so Shopify retries rather than the event being silently dropped) and **401** when the secret is set and the HMAC does not verify. Either way an unsigned request never revalidates a cache tag. A 500 here means the secret is not configured on this deployment yet.
